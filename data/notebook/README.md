## System architecture diagrams
1. The component diagram describes the relationship between each working component of the software. This diagram displays the sequential and essential steps of this project, and the expected outcomes.

2. The class diagram captures the classes and their interactions. This diagram matches the layout of functions in this project, each of which take on unique roles. 

3. The activity diagram describes the direction of workflow, which captures this project’s operations in a logical order.
